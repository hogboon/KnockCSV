# Changelog

All notable changes to **KnockCSV** will be documented in this file.

## \[1.0.0\] - 2026-09-07

### MEGA65

First public release of KnockCSV.

### Added

-   Spreadsheet-style CSV viewer and editor
-   Mouse and keyboard navigation
-   Open, Save and Save As
-   Automatic CSV delimiter detection
-   PETSCII and UTF-8 decoding modes
-   Multiline cell support
-   Full-screen editor for long cell contents
-   Copy, Cut, Paste and Delete
-   Multi-cell selection
-   Insert and delete rows
-   Insert and delete columns
-   Directional Fill and Fill All operations
-   Alphabetical sorting
-   Numeric sorting
-   Length-based sorting
-   Find and Find Next
-   Replace and Replace All
-   Case-sensitive search
-   Configurable header rows and columns
-   Horizontal and vertical scrolling
-   Horizontal split view
-   Vertical split view
-   Independent navigation of split panes
-   80×25 and 80×50 display modes
-   Custom MEGA65 palette and character set
-   Busy pointer during file operations
-   Startup splash screen
-   Overlay-based architecture for editing and search functions

### Notes

This release is the first MEGA65 implementation of KnockCSV.

Future ports to other classic computer platforms, including Commodore 64
and Amiga, are planned.
